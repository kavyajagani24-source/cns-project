📋 Manifest V3 Architecture & Browser API Capabilities

Technical Clarification on Interception Capabilities: In Chromium Manifest V3, extensions cannot perform synchronous, blocking network interception with arbitrary external asynchronous API queries before the initial socket handshake occurs. The deprecated chrome.webRequestBlocking API was permanently removed, and declarativeNetRequest only supports pre-compiled, static declarative rules.

How CyberShield AI Solves This Legally & Effectively:
1. Pre-Navigation Lifecycle Interception: Uses chrome.webNavigation.onBeforeNavigate coupled with high-speed local caching and client-side heuristics to redirect tabs to an internal warning interstitial (warning.html) before loading dangerous pages.
2. Pre-Click DOM Interception: Uses content scripts to intercept clicks on external links prior to navigation submission.
3. Graceful Offline Fallback: If the FastAPI backend is down, local heuristics (Punycode, raw IP address, deceptive tokens, known fixtures) maintain protection without breaking web navigation.
